# Overfitting & Underfitting Visual Lab

GUI-based lab to visualize underfitting vs overfitting by changing model complexity on the same CSV dataset.

## Features
- Load CSV
- Preprocessing: Scaling (None/Standard/MinMax), One-Hot encoding
- Models: Perceptron, MLP, Decision Tree
- Adjustable complexity:
  - MLP hidden layer count
  - Decision Tree max depth
- Displays:
  - Train/Test metrics (Accuracy, Precision, Recall, F1)
  - Confusion matrices
  - Fit label: UNDERFITTING / OVERFITTING / GOOD FIT
  - Train vs Test Accuracy plot
